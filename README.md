# Маркетинговий директор

AI-агент у бічній панелі Chrome. Робить маркетинговий аудит відкритої сторінки за публічними даними й показує звіт із планом дій. Лише аналізує: нічого не публікує й не надсилає.

Це демо. Звіти потребують перевірки людиною.

## Як це працює

```text
Панель Chrome → локальний сервер 127.0.0.1:8787 → claude -p → директор → аналітики → звіт → рецензент → панель
```

- `extension/` — розширення Chrome (Manifest V3): читає сторінку й показує результат.
- `server/server.mjs` — локальний сервер на Node.js без залежностей: приймає сторінку, запускає агента, перевіряє звіт.
- `CLAUDE.md` — інструкції директора.
- `.claude/agents/` — субагенти: сайт, соцмережі, репутація, конкуренти, рецензент.
- `.claude/settings.json` — дозволи агента.
- `scripts/check-report.mjs` — перевірка структури звіту кодом.
- `tests/injection/` — сторінка для перевірки захисту від шкідливих інструкцій.
- `knowledge/` і `run.ps1` — запуск без панелі.

## Запуск на Windows

Потрібні Chrome, Node.js, Git Bash і Claude Code, установлений через npm, з виконаним входом. Запуски витрачають ліміт підписки: вхід через підписку придатний лише для власного демо, для продукту потрібен API-ключ.

1. У `chrome://extensions` увімкніть режим розробника й завантажте папку `extension` як розпаковане розширення.
2. Відкрийте бічну панель і скопіюйте з неї ID розширення.
3. Запустіть сервер із кореня проєкту:
   ```powershell
   $env:CLAUDE_CODE_GIT_BASH_PATH = "C:\Program Files\Git\bin\bash.exe"
   node server/server.mjs <ID розширення>
   ```
   Шлях до `bash.exe` вкажіть свій. Наступні запуски не потребують ID.
4. Вставте у панель токен, який показав сервер. Токен зберігається в `~/.marketing-director/config.json`, поза проєктом. Не передавайте його іншим.
5. Відкрийте сайт і натисніть «Аналізувати». Не запускайте аналіз на сторінках з особистими даними.

## Обмеження

- Працює лише на комп'ютері, де запущено сервер.
- Агент не бачить внутрішніх даних бізнесу й вигляду сторінки.
- Панель читає лише відкриту сторінку.
- Фільтр особистих даних для Instagram ще не перевірено.
